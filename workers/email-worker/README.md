# Email Worker

### Renders Handlebars templates and sends mail via ZeptoMail (transactional) or SES (bulk).

</div>

## 📚 Documentation

> **Full documentation:** [../../docs/components/workers/email-worker.md](../../docs/components/workers/email-worker.md)

---

## 🚀 Quick start

```bash
pnpm --filter @nestlancer/email-worker dev
pnpm --filter @nestlancer/email-worker test
```

Requires RabbitMQ (and PostgreSQL for processors that write). See linked doc for queue name and processors.
